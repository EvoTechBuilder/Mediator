# EvoTechBuilder.Mediator

A lightweight mediator implementation for .NET applications.

This package provides request handling, notification publishing, and request pipeline behaviors.

## Installation

```bash
dotnet add package EvoTechBuilder.Mediator
```

## Features

- Request/response handling.
- Command handling.
- Notification publishing.
- Sequential and parallel notification execution.
- Configurable notification concurrency.
- Request pipeline behaviors.
- CancellationToken propagation.
