# EvoTechBuilder.Mediator.Abstractions

Abstractions and contracts for the EvoTechBuilder.Mediator library.

This package provides the interfaces and types required to define requests, request handlers, notifications, notification handlers, and pipeline behaviors.

## Installation

```bash
dotnet add package EvoTechBuilder.Mediator.Abstractions
```

## Features

- Request and response contracts.
- Request handler contracts.
- Notification contracts.
- Notification handler contracts.
- Pipeline behavior contracts.
- Mediator configuration options.
